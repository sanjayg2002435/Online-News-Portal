
# Online News Portal

## Description
A dynamic Online News Portal developed using PHP and MySQL. It provides secure news management with real-time database integration and an admin dashboard.

## Features
- User Login & Registration
- Admin Dashboard
- News Management
- Categories
- Responsive Design

## Technologies Used
- PHP
- MySQL
- HTML
- CSS
- JavaScript

## Installation
1. Clone the repository
2. Import the SQL file into MySQL
3. Configure the database
4. Run the project using XAMPP
